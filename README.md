# 秦始皇 · 打螺絲 (Qin Shi Huang on the Line)

黑金秦风 × 现代工厂的纯前端单文件 3D 场景：始皇帝站在咸陽青銅裝配線第七號工位，观察 → 对准 → 下压 → 旋拧 → 确认 → 复位，为青铜齿轮箱拧紧两颗六角螺栓。

**在线预览**：https://icradP.github.io/qin-screwdriver/

## 技术要点

- 单文件 HTML，零构建、零依赖安装，three.js 走 CDN（三级回退：jsDelivr → unpkg → esm.sh）
- 自建轨道相机（拖拽旋转 / 滚轮缩放 / 右键平移），无 three 插件依赖
- 两骨骼解析 IK 驱动双臂，肘部极点外张，避免与躯干穿插
- 严格时序同步：刀尖 Y 与螺丝头顶同源，工具与螺丝共用同一旋转量（6 整圈，六角头回到原相位）
- 工件对象池复用：排队 → 工位 → 加工 → 离开 → 回收入线
- 性能：几何/材质共享、冕旒珠串实例化、火花粒子池、单光源阴影、按帧耗时自动降档

## 交互

| 操作 | 说明 |
| --- | --- |
| 拖拽 / 滚轮 / 右键拖拽 | 旋转 / 缩放 / 平移 |
| 点击工件 | 加急 |
| 点击控制台红、绿按钮 | 急停 / 复位 |
| 空格 | 暂停继续 |
| 1 / 2 / 3 / 4 | 全景 / 特写 / 侧视 / 俯瞰 |
| E / R | 急停 / 复位视角 |

## 本地运行

直接双击 `index.html` 即可（需联网加载 three.js 与支持 WebGL 的浏览器）。

> 仓库根目录的 `index.html` 与本地 `qin-screwdriver.html` 内容一致，前者用于 GitHub Pages 入口。
